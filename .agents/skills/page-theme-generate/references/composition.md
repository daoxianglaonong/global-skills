# 构图判断（三节，都不是门）

出处：`docs/vercel-design-md-vs-huaweicloud-page-theme.md` §5.1。

**本文件不加门、不改判据、不进任何退出码。** 已有门管的一律不复述，只点名：色值字面量 / 闭集 /
涂色 / 序列拍板 / 资产 `DESIGN.md` 的 Don't 节 / `voice.md` 禁词，全在 `SKILL.md`「自检门」十二道；
连排与同型过用已由 `lint-outline` 的形状提示 `repeated-taxonomy-run` / `single-pattern-overuse` 报，
本文件不再写一遍。门判可证伪的事实，本文件判门射程外的取舍，裁决人是用户不是 `lint-floor.mjs`。

## 1. 构图 Don't

**不带触发条件的条目无效。** 每条形如「条件 → 禁 → 出路」，条件必须指得出资产里的哪一行；条件不
成立本条不开口。

| id | 触发条件（全成立才开口） | 禁 | 出路 |
| --- | --- | --- | --- |
| C1 槽外增生 | 某层用型 `X`，产物这一层出现了 `floor-index.json` 里 `X.slots` 没有的槽（装饰图标、eyebrow、徽标、统计条） | 为「看着完整」给卡片补图标、给标题补 eyebrow | 只填该型 `slots` 列出的槽；确需新槽按形态缺口写进大纲让人拍板 |
| C2 可选槽全填 | 某层把该型 `required: false` 的槽全部填满，而大纲「关键内容点」一列没写这些内容 | 用可选槽把版面撑满 | 只填大纲点过的槽，其余留空 |
| C3 CTA 泛滥 | 产物 `taxonomy: cta` 的层数超过已采页上限（现役 `huaweicloud-com` 的 `pages.*.sequence` 11 条里 10 条 ≤ 1 层，最多 2 层） | 每层结尾都收一个主钮 | 全页留 ≤ 1 层 cta，其余动作降级成文内链接 |
| C4 无出处数字 | 文案里的百分比 / 倍数 / 时延既不来自用户输入，也不在 `voice.md` §V2 `stat_value` 的口径内 | 写「99.99%」「10x」「毫秒级」撑说服力 | 按值缺口 omit（`generate.md`「缺口二分」），不编 |
| C5 空承诺标题 | `heading` 槽的文案把产品名换成任意别的产品仍然成立 | 「赋能业务创新」「一站式解决方案」这类可移植空句 | 用本页真实对象重写，口吻档位查 `voice.md` §V2 `heading` |

**两条元规则，优先于上表：**

- **一张难看截图不得升级成全站禁令。** 新增一条前先在资产里找反例：该构图在 `patterns/` 或
  `pages.*.sequence` 里有观测，就只能收窄触发条件，不许写成死禁。
- **单模型偶发不进公共规则。** 只出现过一次的毛病就地改产物；进本表要求同一触发条件在 ≥ 2 次
  独立生成里复现。

### 华为云真站豁免

这三样在 `huaweicloud-com` 上是实测记录，不是 AI 套路，上表任何一条都不得用来禁它们：

| 被豁免的 | 依据 |
| --- | --- |
| 门户能力栅格（多列卡片铺能力） | `floor-index.json` 53 个型里 10 个是 `feature.grid-*`，2 / 3 / 4 / 5 列都有观测 |

## 2. 读者工作四问

**射程：只对非已采序列的新页**——骨架选型与共现回退那两档。已采页序列以 `pages.*.sequence` 实测
为准，不套报告站的信息架构，本节整节不开口。

骨架选型前答完，答案落进大纲的「关键内容点」一列：

| # | 问 | 不答会怎样 |
| --- | --- | --- |
| 1 | 谁打开这页 | 楼层取舍无据，只能按型目录顺序堆 |
| 2 | 他要做决定还是要了解 | 决定型页缺对比与规格，了解型页被塞满 CTA |
| 3 | 最强证据是什么（数字 / 客户 / 图 / 规格表） | 最强证据排到第七层，首屏是空话 |
| 4 | 什么限制会改变解释（地域 / 版本 / 计费 / 合规） | 结论写死，读者按错误前提行动 |

**不是门，不进退出码，不改 trace 任何字段。** 只影响大纲文案与楼层取舍；程度问题由拍板的人裁，
大纲阶段本来就为这件事存在（`SKILL.md`「楼层序列与大纲」）。

## 3. 第一视口自检

**只在 generate 的私下修订遍做**：写完产物、跑门之前，自己看，不写进产物、不写成结论。

- **squint**：第一视口缩到看不清字，还剩几块？分不出主次两块，是层级没做出来。
- **text-mask**：遮掉第一视口全部文字，还看得出这页在讲什么吗？看不出就是全靠文案撑。
- 判出问题改产物再跑门。门退 1 以门为准，本节不构成放行理由。

**为什么不进 `page-theme-audit`：** 那侧的 prose-invariance 靠「只读白名单内的机读字段、不读生成侧
任何自由文本」成立（见该包 `SKILL.md`「不读说辞」）。把「第一屏是不是主张」做成审计门，等于逼审计
读生成侧说辞并给它评分，生成 / 审计分权当场破掉。

截图可以进 generate trace 的读图声明，但审计只核路径在不在、解不解得开（`image-evidence`），
不核图里有没有主张。
