# 刷主题模式

保内容与结构，只换主题。原页可以是本地文件、项目源码、DOM 快照；本包不负责抓取线上页。

## 第一次调用：出表

1. 圈定射程：要改哪几份文件。只改这几份。
2. `baseline` 记原页（文本、链接、图片、DOM 结构）。
3. `inventory --format md` 出底稿：同一源值、同一用途合一行，带处数、例与候选 token，没有裁决列。
4. 模型在底稿上补 `token / 匹配 / 决定` 三列（决定只有「映射」「保留」），得到下面这一张表，回话，停。

```text
资产：<目录>    射程：<文件列表>

| # | 源值 | 用途 | 处数 | 例 | token | 匹配 | 决定 |
| 1 | #333333 | 正文色 | 14 | .card p { color } | --acme-text | 近似 | 映射 |
| 2 | #0a66c2 | 主按钮底 | 3 | .btn { background } | --acme-accent | 近似 | 映射 |
| 3 | #ff5a00 | 促销角标底 | 1 | .badge { background } | — | 无 | 保留 |
| 4 | Arial, sans-serif | 正文字体 | 1 | body { font-family } | --acme-font | 替换 | 映射 |
| 5 | 4px | 按钮圆角 | 3 | .btn { border-radius } | --acme-radius-control | 近似 | 映射 |

请整表确认，或只写要改的行号与新决定。
```

- 一张表：颜色、字体族、字号、圆角、间距、阴影都在里面，用「用途」区分。
- 用途写人话（正文色、卡片底、分隔线、主按钮底），不用固定枚举。
- 同一源值不同用途分行：`#ffffff` 作页面底与作按钮字是两行，可选不同 token。
- 匹配三档：`精确` 值相同；`近似` 值不同但用途对得上；`无` 资产里没有合适 token。
- `无` 默认「保留」。不为凑满表去造 token，也不硬配一个用途不对的 token。
- 选 token 以候选的 `usage` 与 `DESIGN.md` 的 Do / Don't 为准，ΔE 只是辅助：工具已把用途、选择器角色（按钮、链接…）和状态对得上的候选排前，但它只做关键词匹配；色差最小的候选用途不对（如资产写明「不要把辅助蓝当主按钮」）就不选它。
- 几何（圆角、尺寸、间距）资产没有对应 token 时保留原值，不按组件样张的形态改（样张画了胶囊但没印圆角值，原页 4px 照旧），摘要「规范缺口」列出。
- 带透明度的源值（`rgba(0,0,0,.08)`）：选 token 后写
  `color-mix(in srgb, var(--x) 8%, transparent)`，在「例」列注明。

## 第二次调用：执行

前提：用户确认过整表。没有确认就不动文件。

1. 引入 `tokens.css`：在原 CSS 顶部 `@import`，或项目原生方式；不往 HTML 加节点。
2. 「映射」行：该行每一处源值换成 `var(<token>)`。
3. 「保留」行：一处不动。
4. 不改：文本、链接、图片、DOM 结构、class / id、选择器、`@media` 条件。
5. 不新增资产外变量；不在产物里重新声明资产变量的值。

## 验收

| 查 | 要求 |
| --- | --- |
| `baseline` 比对 | 文本、链接、图片、DOM 结构零漂移；有漂移改回再查 |
| `lint` | 阻断项只许来自「保留」行；其他红项修掉 |
| 兑现 | 「映射」行处数全部换掉；摘要写已换 / 保留行数 |
| `capture` | 前后各三宽，放在一起交 |

`baseline` 管不到的靠射程：JS 运行时拼的文字、没圈进射程的文件。摘要里写清射程。
要改文案或结构就不是刷主题，转创作模式。

## 资产升级

项目已按旧版资产刷过主题，要换到新版（看 `CHANGELOG.md` 改了什么）。不出映射表，不停：

1. `baseline snapshot` 记当前页。
2. 换文件：用新版 `css --out` 出副本（`--scope` 照旧），替换旧的 `tokens.<旧版>.css`，入口引用改名；用了 `components.css` 的同样换。
3. `lint`：`unknown-var` 阻断（新版删掉的变量）按 CHANGELOG 换成替代变量；`deprecated-var` 报警按 message 给的新名替换，主版本删除前清完。
4. `baseline compare`：零漂移。
5. `capture` 前后三宽对照；摘要写新旧版本号、替换了哪些变量、剩余报警。
